# Catapulta Orc

Modelo original animado criado pelo MCP do Blender aberto.

Fonte editável: `orc_catapult_v1.blend`; jogo: `orc_catapult_v1.glb`. Atlas pixelado embutido no GLB e empacotado no Blender; filtro nearest. Frente -Y no Blender / +Z no Godot. Origem no solo, escala aplicada.

Altura: 1.8 m. Madeira escura, ferro, couro, corda e chifres orcs. Peças separadas no Blender; mesh consolidada na exportação. Animações: Catapult_Idle, Catapult_Walk, Catapult_Attack, Catapult_DemolitionAmmo. Rodas e mecanismos com pesos rígidos. Idle/Walk em loop; ataques recuperam a posição de repouso. Disparos do colosso alternam os dois canhões.
