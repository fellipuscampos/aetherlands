# Bombarda Orc

Modelo original animado criado pelo MCP do Blender aberto.

Fonte editável: `orc_bombard_v1.blend`; jogo: `orc_bombard_v1.glb`. Atlas pixelado embutido no GLB e empacotado no Blender; filtro nearest. Frente -Y no Blender / +Z no Godot. Origem no solo, escala aplicada.

Altura: 1.8 m. Madeira escura, ferro, couro, corda e chifres orcs. Peças separadas no Blender; mesh consolidada na exportação. Animações: Bombard_Idle, Bombard_Walk, Bombard_Attack, Bombard_DemolitionAmmo, Bombard_PreparedBombardment. Rodas e mecanismos com pesos rígidos. Idle/Walk em loop; ataques recuperam a posição de repouso. Disparos do colosso alternam os dois canhões.
