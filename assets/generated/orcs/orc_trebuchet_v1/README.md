# Trebuchet Orc

Modelo original animado criado pelo MCP do Blender aberto.

Fonte editável: `orc_trebuchet_v1.blend`; jogo: `orc_trebuchet_v1.glb`. Atlas pixelado embutido no GLB e empacotado no Blender; filtro nearest. Frente -Y no Blender / +Z no Godot. Origem no solo, escala aplicada.

Altura: 1.8 m. Madeira escura, ferro, couro, corda e chifres orcs. Peças separadas no Blender; mesh consolidada na exportação. Animações: Trebuchet_Idle, Trebuchet_Walk, Trebuchet_Attack, Trebuchet_DemolitionAmmo, Trebuchet_PreparedBombardment. Rodas e mecanismos com pesos rígidos. Idle/Walk em loop; ataques recuperam a posição de repouso. Disparos do colosso alternam os dois canhões.
