# Oficina — human

Alvenaria de blocos de pedra, cantaria nos pilares e bases, telhados de ardósia azul. Madeira nos móveis, portas e mecanismos. Oficina de infraestrutura, uma única versão sem evolução. Revisão: Telhados retangulares com beirais retos; coberturas hexagonais preservadas. Apoios revisados por contato. Oficina e universidade élficas com duas águas, conforme os salões anteriores.

Criado pelo **Blender MCP**. Categoria `industry`, ID `v2_building_workshop`. Uma única versão por civilização; sem evoluções.

- 64 peças editáveis, 988 triângulos, atlas 1024² com filtro nearest.
- .blend com atlas empacotados; .glb com duas texturas embutidas.
- Escala nativa do tile, origem central no solo; frente −Y no Blender / +Z no Godot.
- Malha Faction separada para a cor do dono.
