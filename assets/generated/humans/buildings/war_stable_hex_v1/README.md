# Estábulo de Guerra

Alvenaria de blocos de pedra, pilares com bases e capitéis de cantaria, telhados azuis; madeira reservada a portas, cercas, móveis e mecanismos.

Revisão de arquitetura de 2026-10-09 pelo **Blender MCP**. Baias, cavalos, pátio e equipamentos preservados; paredes e pilares principais agora usam pedra.

- 182 peças editáveis, 2348 triângulos, atlas 2048² com filtro nearest.
- Fonte .blend com texturas empacotadas e exportação .glb com atlas embutidos.
- Origem central no solo; frente −Y no Blender / +Z no Godot.
- Mantém o caminho e o ID usados pelo catálogo do jogo.

Prévias: [três quartos](previews/three_quarter.png), [mapa](previews/game_top.png), [topo](previews/top.png), [traseira](previews/back.png).

Os arquivos anteriores estão em art_source/buildings_before_architecture_revision. O relatório JSON lista as peças alteradas e verificações.
