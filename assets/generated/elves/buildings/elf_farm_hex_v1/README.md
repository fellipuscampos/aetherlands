# Fazenda — elf

Pedra clara e madeira esbelta com apoios ramificados, pavilhões abertos, telhados verdes altos com cantos facetados e folhas douradas. Fazenda de infraestrutura, uma única versão sem evolução. Revisão: Telhados retangulares com beirais retos; coberturas hexagonais preservadas. Apoios revisados por contato. Oficina e universidade élficas com duas águas, conforme os salões anteriores. Junções ajustadas para eliminar faces coplanares expostas.

Criado pelo **Blender MCP**. Categoria `logistics`, ID `v2_building_farm`. Uma única versão por civilização; sem evoluções.

- 153 peças editáveis, 1924 triângulos, atlas 1024² com filtro nearest.
- .blend com atlas empacotados; .glb com duas texturas embutidas.
- Escala nativa do tile, origem central no solo; frente −Y no Blender / +Z no Godot.
- Malha Faction separada para a cor do dono.
