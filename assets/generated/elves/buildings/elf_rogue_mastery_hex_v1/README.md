# Refúgio das Sombras — Elfos

Refúgio élfico de duas casas suspensas: árvores e estacas sustentam pods hexagonais em alturas distintas, unidos por ponte cercada; escadaria, alçapão e treino de facas no solo. A guilda evolui para uma rede escondida entre copas.

Doutrina: `rogue`. Grande construção associada a `v2_legendary_shadow_master`; requisito no cadastro: `v2_building_rogue_guild`.

Referência militar básica da própria civilização: `assets/generated/elves/buildings/elf_rogue_guild_hex_v1`. Planta e volumes avançados próprios, sem copiar a arquitetura entre raças.

- `.blend`: cena isolada, peças editáveis e texturas empacotadas.
- `.glb`: grupos consolidados, atlas embutidos e nearest, sem rig/animação/câmera/luz.

186 peças, 2448 triângulos, atlas 1024².

Origem central no solo; frente −Y no Blender / +Z no Godot. Base pointy-top raio 0,92 para tile raio 1, escala 1; todas as peças dentro das seis bordas.
