# Poço de escavação

Funil profundo entre placas de areia rompida, túneis escuros e cascas segmentadas.

Criado no Blender pelo MCP. Fonte editável em `.blend`, malha de runtime em `.glb`.
Frente +Z no glTF; origem no chão; escala 1:1. Raio máximo 0,78 m: cabe no hex de raio 1 m.
Uma malha, um material; atlas albedo/emissão embutidos, filtro nearest, 64 px/m.
As peças de estúdio e os anchors de referência não estão no GLB.
Arte estática: spawn, líder, dano e remoção do covil continuam responsabilidade do jogo.
A pasta-mãe tem `.gdignore` para impedir importação automática durante trabalhos simultâneos.
