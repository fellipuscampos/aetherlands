# Oficina — dwarf

Granito, pilares espessos, sapatas de pedra e cintas de cobre. Telhados baixos de ardósia escura e engenharia mecânica robusta. Oficina de infraestrutura, uma única versão sem evolução. Revisão: Telhados retangulares com beirais retos; coberturas hexagonais preservadas. Apoios revisados por contato. Oficina e universidade élficas com duas águas, conforme os salões anteriores. Junções ajustadas para eliminar faces coplanares expostas.

Criado pelo **Blender MCP**. Categoria `industry`, ID `v2_building_workshop`. Uma única versão por civilização; sem evoluções.

- 87 peças editáveis, 1268 triângulos, atlas 1024² com filtro nearest.
- .blend com atlas empacotados; .glb com duas texturas embutidas.
- Escala nativa do tile, origem central no solo; frente −Y no Blender / +Z no Godot.
- Malha Faction separada para a cor do dono.
