# Construções militares — Anões e Elfos

[Grandes construções militares — quatro civilizações](GRAND_MILITARY_CATALOG.md).

As duas famílias têm as seis construções comuns. **Assets preparados, sem integração no jogo.** Cada pasta contém `.blend`, `.glb`, dois atlas PNG, relatório, README e quatro prévias. Base militar hexadecimal pointy-top de raio 0,92 para tile de raio 1; unidades supremas ficam nos prédios próprios.

Anões: granito, ardósia escura, cobre e detalhes azuis. Elfos: pedra clara, madeira, telhados verdes, folhas douradas e vegetação.
